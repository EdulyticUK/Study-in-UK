# Edulytic - UK Study Consultants Landing Page

A modern, responsive landing page for Edulytic, a UK-based study consultancy serving Pakistani students seeking higher education in the United Kingdom.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Contact Form**: Interactive form for student inquiries
- **Performance Optimized**: Fast loading with optimized images and code
- **SEO Friendly**: Proper meta tags and semantic HTML structure

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript
- Font Awesome Icons
- Google Fonts (Inter)
